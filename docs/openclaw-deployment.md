# OpenClaw AWS Deployment Plan

## Architecture

Deploy OpenClaw on a single EC2 instance (t3.medium) with Tailscale for secure access. No public ports exposed except SSH as fallback - all access is via Tailscale.

### Components
- **EC2 Instance**: t3.medium (4GB RAM, 2 vCPU) running Ubuntu 24.04 LTS
- **Tailscale**: Mesh VPN for secure access without exposing ports publicly
- **Docker**: OpenClaw runs as a Docker container
- **EBS**: 30GB gp3 root volume for persistence

### Cost
- t3.medium on-demand: ~$30/month
- 30GB gp3 EBS: ~$2.40/month
- **Total: ~$33/month**

### Network
- Reuses the existing Y-Sweet VPC (`10.0.0.0/16`) and subnet A (`10.0.1.0/24`)
- Security group: SSH (port 22) only for fallback, all egress allowed
- OpenClaw gateway (port 18789) accessible only via Tailscale
- Tailscale `serve` proxies port 18789 over HTTPS on the tailnet

## What You Need to Provide

### Required
1. **Tailscale Auth Key** - A reusable auth key from your Tailscale admin console
   - Go to: https://login.tailscale.com/admin/settings/keys
   - Create an auth key (reusable, ephemeral recommended)
   - This lets the EC2 instance join your tailnet automatically

2. **Tailnet DNS Name** - Your tailnet's MagicDNS suffix
   - Found at: https://login.tailscale.com/admin/dns
   - Looks like: `tail12345.ts.net` or `yourdomain.com` if using a custom domain

### Already Available (in Pulumi config)
- **Anthropic API Key** - Already stored as `anthropic_api_key`

### Generated Automatically
- **SSH Key Pair** - Generated by Pulumi for emergency access
- **OpenClaw Gateway Token** - Generated during setup for Control UI auth

## Deployment Steps

1. Store Tailscale secrets in Pulumi config
2. Add OpenClaw infrastructure to `lambda/index.ts`
3. Run `pulumi up` to create the EC2 instance
4. Cloud-init automatically:
   - Installs Docker, Node.js 22, Tailscale
   - Joins your tailnet
   - Installs OpenClaw via npm
   - Runs non-interactive onboarding with Anthropic API key
   - Starts the gateway daemon
   - Configures `tailscale serve` to expose gateway on tailnet
5. Access OpenClaw at `https://<hostname>.<tailnet>/`

## Verification Tests

1. **EC2 Instance Running**: `aws ec2 describe-instances` shows running state
2. **Tailscale Connected**: Instance appears in Tailscale admin
3. **SSH via Tailscale**: `ssh ubuntu@<tailscale-ip>` works
4. **OpenClaw Gateway**: `curl http://<tailscale-ip>:18789` responds
5. **OpenClaw Health**: `docker compose exec openclaw-gateway node dist/index.js health --token $TOKEN`
6. **Control UI**: Browser access to `https://<hostname>.<tailnet>/` shows OpenClaw dashboard
